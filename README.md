# MVP GirliES

Este projeto é desenvolvido com Node.js e TypeScript.

## Requisitos

- Node.js
- npm

## Primeiros Passos

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

O projeto foi configurado para rodar em TypeScript diretamente com o Node.js, usando o ambiente de execução do TypeScript.
